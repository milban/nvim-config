# Vim 편집 언어

Vim에서는 텍스트를 먼저 선택한 뒤 작업하기보다, **무엇을 어떻게 편집할지** 명령으로 표현한다.

```text
[횟수] + 동작(operator) + 이동(motion) 또는 텍스트 객체(text object)
```

예를 들어 `ciw`는 다음과 같이 읽을 수 있다.

```text
c   change: 대상을 변경한다
iw  inner word: 현재 단어 내부를 대상으로 한다
```

결과적으로 `ciw`는 현재 단어를 지우고 Insert mode로 들어간다.

## 1. 이동: Motion

### 단어 단위 이동

| 명령 | 의미 |
|---|---|
| `w` | 다음 단어의 시작으로 이동 |
| `b` | 이전 단어의 시작으로 이동 |
| `e` | 현재 또는 다음 단어의 끝으로 이동 |
| `ge` | 이전 단어의 끝으로 이동 |

### 줄 안에서 이동

| 명령 | 의미 |
|---|---|
| `0` | 줄의 첫 번째 칸으로 이동 |
| `^` | 줄의 첫 번째 글자로 이동 |
| `$` | 줄의 끝으로 이동 |
| `f{문자}` | 현재 줄에서 다음 `{문자}` 위로 이동 |
| `t{문자}` | 현재 줄에서 다음 `{문자}` 직전으로 이동 |
| `F{문자}` | 현재 줄에서 이전 `{문자}` 위로 이동 |
| `T{문자}` | 현재 줄에서 이전 `{문자}` 직후로 이동 |
| `;` | 마지막 `f`, `t`, `F`, `T` 이동 반복 |
| `,` | 마지막 `f`, `t`, `F`, `T` 이동을 반대 방향으로 반복 |

### 파일 안에서 이동

| 명령 | 의미 |
|---|---|
| `gg` | 파일의 첫 줄로 이동 |
| `G` | 파일의 마지막 줄로 이동 |
| `{숫자}G` | 지정한 줄로 이동. 예: `11G` |
| `{` | 이전 문단으로 이동 |
| `}` | 다음 문단으로 이동 |
| `%` | 서로 짝이 되는 괄호로 이동 |

## 2. 동작: Operator

Operator를 입력하면 Neovim은 그 동작을 적용할 대상을 기다린다.

| 명령 | 의미 |
|---|---|
| `d` | 삭제하고 레지스터에 저장(delete) |
| `c` | 삭제한 뒤 Insert mode 진입(change) |
| `y` | 복사(yank) |
| `>` | 들여쓰기 |
| `<` | 내어쓰기 |
| `=` | 자동 들여쓰기 |

Operator와 motion을 조합할 수 있다.

```text
d + w = dw    다음 단어 경계까지 삭제
c + $ = c$    현재 위치부터 줄 끝까지 변경
y + } = y}    다음 문단까지 복사
```

같은 operator를 두 번 입력하면 현재 줄 전체에 적용된다.

```text
dd    현재 줄 삭제
cc    현재 줄을 변경
yy    현재 줄 복사
>>    현재 줄 들여쓰기
```

## 3. 텍스트 객체: Text Object

텍스트 객체는 커서 주변에 있는 의미 있는 대상을 표현한다.

```text
i = inner: 구분자를 제외한 내부
a = around: 구분자나 주변 공백까지 포함
```

| 명령 | 의미 |
|---|---|
| `iw` | 현재 단어 내부 |
| `aw` | 현재 단어와 주변 공백 |
| `i"` | 큰따옴표 내부 |
| `a"` | 큰따옴표를 포함한 전체 |
| `i'` | 작은따옴표 내부 |
| `a'` | 작은따옴표를 포함한 전체 |
| `i(` 또는 `ib` | 소괄호 내부 |
| `a(` 또는 `ab` | 소괄호를 포함한 전체 |
| `i{` 또는 `iB` | 중괄호 내부 |
| `a{` 또는 `aB` | 중괄호를 포함한 전체 |
| `ip` | 현재 문단 내부 |
| `ap` | 현재 문단과 주변 공백 |

Operator와 텍스트 객체를 조합하면 Visual mode로 먼저 선택하지 않아도 된다.

| 명령 | 의미 |
|---|---|
| `ciw` | 현재 단어 변경 |
| `daw` | 현재 단어와 주변 공백 삭제 |
| `di"` | 큰따옴표 안의 내용 삭제 |
| `ca(` | 소괄호와 그 안의 내용 변경 |
| `yap` | 현재 문단 복사 |
| `=i{` | 현재 중괄호 내부 자동 들여쓰기 |

## 4. 횟수: Count

명령 앞에 숫자를 붙이면 동작을 여러 번 수행하거나 더 먼 대상을 지정할 수 있다.

| 명령 | 의미 |
|---|---|
| `3w` | 세 단어 앞으로 이동 |
| `2b` | 두 단어 뒤로 이동 |
| `3dd` | 세 줄 삭제 |
| `2ciw` | 현재 위치부터 두 단어를 변경 |
| `5j` | 다섯 줄 아래로 이동 |

숫자를 반복해서 누르기보다 의미 있는 motion이나 검색을 우선 사용하는 것이 좋다.

## 5. 변경 반복과 실행 취소

| 명령 | 의미 |
|---|---|
| `u` | 마지막 변경 실행 취소 |
| `<C-r>` | 취소한 변경을 다시 적용 |
| `.` | 마지막 변경 반복 |

`.`은 Vim의 핵심 명령 중 하나다. 한 번의 변경을 잘 구성하면 다른 위치에서 같은 작업을 즉시 반복할 수 있다.

예시:

1. 어떤 단어 위에서 `ciw`를 입력한다.
2. 새로운 단어를 입력하고 `Esc`를 누른다.
3. `w`로 다음 대상까지 이동한다.
4. `.`을 눌러 같은 변경을 반복한다.

## 6. 검색

| 명령 | 의미 |
|---|---|
| `/{검색어}` | 현재 위치에서 아래 방향으로 검색 |
| `?{검색어}` | 현재 위치에서 위 방향으로 검색 |
| `n` | 같은 방향의 다음 검색 결과 |
| `N` | 반대 방향의 다음 검색 결과 |
| `*` | 커서 아래 단어를 아래 방향으로 검색 |
| `#` | 커서 아래 단어를 위 방향으로 검색 |

검색 결과까지의 이동도 operator와 조합할 수 있다.

```text
d/target<Enter>    현재 위치부터 target까지 삭제
```

## 7. 창 이동

이 문서를 코드와 나란히 열었을 때 사용할 수 있다.

| 명령 | 의미 |
|---|---|
| `<C-w>h` | 왼쪽 창으로 이동 |
| `<C-w>j` | 아래쪽 창으로 이동 |
| `<C-w>k` | 위쪽 창으로 이동 |
| `<C-w>l` | 오른쪽 창으로 이동 |
| `<C-w>q` | 현재 창 닫기 |
| `<C-w>=` | 창 크기를 균등하게 조절 |

`<C-w>h`는 Ctrl을 누른 채 `w`를 입력하고, 키에서 손을 뗀 뒤 `h`를 입력한다.

## 8. 존재하지 않는 파일 생성하고 저장하기

`:edit`은 기존 파일을 여는 명령이지만, 아직 존재하지 않는 경로를 지정하면 새 파일 버퍼를 준비한다. 이 시점에는 실제 파일이 생성되지 않으며 `:write`로 저장해야 디스크에 파일이 생긴다.

```vim
:edit notes/today.md
```

`:edit`은 `:e`로 줄여 쓸 수도 있다.

```vim
:e notes/today.md
```

새 파일을 작성하고 저장하는 순서는 다음과 같다.

1. `:edit {파일 경로}`로 새 파일 버퍼를 연다.
2. `i`를 눌러 Insert mode로 들어간다.
3. 내용을 작성한다.
4. `Esc`를 눌러 Normal mode로 돌아온다.
5. `:write` 또는 `:w`로 파일을 저장한다.

```text
:edit practice.lua
i
-- 내용을 작성한다
<Esc>
:write
```

상위 디렉터리가 존재하지 않으면 일반적인 `:write`는 실패한다. Neovim에서는 `++p`를 사용해 필요한 부모 디렉터리와 파일을 함께 만들 수 있다.

```vim
:edit lua/learning/example.lua
:write ++p
```

현재 작업 디렉터리는 `:pwd`로 확인할 수 있다. 상대 경로는 이 작업 디렉터리를 기준으로 해석된다.

| 명령 | 의미 |
|---|---|
| `:edit {경로}` 또는 `:e {경로}` | 파일을 열거나 새 파일 버퍼 준비 |
| `:write` 또는 `:w` | 현재 내용을 파일에 저장 |
| `:write ++p` | 부모 디렉터리가 없다면 함께 생성하여 저장 |
| `:wq` | 저장하고 현재 창 닫기 |
| `:q!` | 변경 내용을 저장하지 않고 현재 창 닫기 |
| `:pwd` | 현재 작업 디렉터리 확인 |

명령 이름은 `:edit`이다. `:eidt`는 오타이므로 실행되지 않는다.

## 9. 코드 진단 확인과 이동

LSP가 현재 버퍼에 연결되면 오류와 경고가 진단 항목으로 등록된다. Neovim 설정에 따라 메시지가 코드 옆에 바로 보이지 않을 수 있으므로 이동 명령과 진단 팝업을 함께 사용한다.

| 명령 | 의미 |
|---|---|
| `]d` | 다음 진단으로 이동 |
| `[d` | 이전 진단으로 이동 |
| `]D` | 현재 버퍼의 마지막 진단으로 이동 |
| `[D` | 현재 버퍼의 첫 번째 진단으로 이동 |
| `<C-w>d` | 커서 위치의 진단 메시지를 팝업으로 표시 |

`<C-w>d`는 Ctrl을 누른 채 `w`를 입력하고, 키에서 손을 뗀 뒤 `d`를 입력한다.

진단을 연습할 때는 실제 설정 파일 대신 임시 파일을 사용하면 안전하다.

```vim
:edit /tmp/lsp-test.lua
```

```lua
local unused_value = 10

unknown_global()
```

파일을 실행하지 않은 상태에서 `]d`와 `[d`로 진단 사이를 이동하고, `<C-w>d`로 메시지를 확인한다. 연습이 끝나면 `:q!`로 저장하지 않고 닫을 수 있다.

## 10. 연습장

아래 텍스트를 자유롭게 수정한 뒤 `u`로 되돌리며 연습한다. 문서 자체를 보존하고 싶다면 저장하지 않고 `:q!`로 닫는다.

```text
change this word
delete "only this content"
replace (everything in here)
edit {the value inside these braces}
repeat apple repeat apple repeat apple
move from the beginning to the end of this line
```

### 연습 1: 이동

- [ ] `w`, `b`, `e`만 사용해 단어 사이를 이동한다.
- [ ] `0`, `^`, `$`를 사용해 줄의 시작과 끝으로 이동한다.
- [ ] `f"`를 사용해 큰따옴표로 이동한다.
- [ ] `%`를 사용해 여는 괄호와 닫는 괄호 사이를 이동한다.

### 연습 2: Operator와 Text Object

- [ ] `ciw`로 `word`를 다른 단어로 변경한다.
- [ ] `di"`로 큰따옴표 안의 내용만 삭제한다.
- [ ] `ci(`로 소괄호 안의 내용만 변경한다.
- [ ] `da{`로 중괄호와 그 안의 내용을 삭제한다.
- [ ] 각 변경을 `u`로 되돌린다.

### 연습 3: 반복

- [ ] 첫 번째 `apple`을 `orange`로 변경한다.
- [ ] `w` 또는 `/apple`로 다음 `apple`까지 이동한다.
- [ ] `.`으로 같은 변경을 반복한다.
- [ ] `u`와 `<C-r>`로 변경 이력을 앞뒤로 이동한다.

## 11. 이번 단계의 목표

다음 명령을 생각하지 않고 사용할 수 있을 때까지 반복한다.

```text
w  b  e  0  ^  $
f  t  ;  ,
d  c  y
iw  aw  i"  a"  i(  a(
u  <C-r>  .
/  n  N
:edit  :write  :write ++p
[d  ]d  <C-w>d
```

모든 명령을 한 번에 외우는 것이 목표는 아니다. 실제 편집 중 반복해서 마주치는 동작부터 익히고, 익숙해진 명령은 이후 문서의 “완료” 영역으로 옮긴다.
