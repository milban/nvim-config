# 복사 이력과 레지스터

Yanky가 복사·삭제·변경으로 레지스터에 들어오는 최근 100개 항목을 보관합니다.
이력은 ShaDa에 저장되어 Neovim을 정상 종료하고 다시 실행해도 유지됩니다.
설치 전에 사라진 복사 이력을 복구하는 기능은 아닙니다.
이 문서는 `:YankHelp` 또는 `Space yh`로 여실 수 있습니다.

## 복사와 붙여넣기

| 입력 | 동작 |
|---|---|
| `yy` | 현재 줄 복사 |
| Visual mode에서 선택 후 `y` | 선택한 내용 복사 |
| Normal mode에서 `p` / `P` | 커서 뒤 / 앞에 붙여넣기 (줄 단위 복사는 아래 / 위) |
| 붙여넣기 직후 `Ctrl-p` / `Ctrl-n` | 붙여넣은 내용을 더 오래된 / 더 최근 이력으로 교체 |
| Visual mode에서 `p` | 선택 영역을 교체하고 지워진 내용을 기본 레지스터에 저장 |
| Visual mode에서 `P` | 선택 영역을 교체하며 기존 레지스터 내용 유지 |

이력 순환은 일반 파일에서 Normal mode의 `p`, `P`, `gp`, `gP` 또는 이력 목록으로 붙여넣은 직후 사용합니다.
이후 다른 편집을 하면 순환이 종료됩니다. Visual mode의 교체와 터미널 붙여넣기에는 이력 순환을 적용하지 않습니다.

## 목록에서 검색하고 선택하기

1. Normal mode에서 `:YankyRingHistory` 또는 `Space fy`를 실행합니다.
2. 찾을 내용을 입력하면 기존 `mini.pick` 창에서 목록이 필터링됩니다.
3. `Ctrl-n` / `Ctrl-p`로 항목을 이동하고 `Enter`로 선택해 붙여넣습니다.
4. 취소하시려면 `Esc`를 누르시면 됩니다.

목록 안의 `Ctrl-n` / `Ctrl-p`는 항목 이동이며, 편집 화면에서는 붙여넣은 내용의 이력 순환입니다.
전체 이력을 지우시려면 `:YankyClearHistory`를 실행하시면 됩니다.

## LazyGit 커밋 메시지에 사용하기

1. `Space gg`로 LazyGit을 열고 Files 패널에서 `c`로 커밋 메시지 입력창을 엽니다.
2. `Ctrl-\` 다음 `Ctrl-n`을 눌러 Neovim의 Normal mode로 전환합니다.
3. `Space fy` 또는 `:YankyRingHistory`로 이력을 엽니다.
4. 항목을 검색한 뒤 `Enter`로 선택하면 커밋 입력창에 붙여넣고 입력 모드로 돌아갑니다.
5. 메시지를 검토한 뒤 별도로 `Enter`를 눌러 커밋합니다.

줄 전체를 복사했을 때 따라오는 마지막 개행은 터미널에 붙여넣을 때 제외합니다.
LazyGit 안에서 바로 `Space fy`를 누르면 LazyGit으로 전달되므로 2번의 모드 전환이 필요합니다.

## 레지스터 직접 사용하기

| 입력 | 동작 |
|---|---|
| `:registers` 또는 `:reg` | 레지스터 목록 확인 |
| `"0p` | 기본 yank로 마지막 복사한 내용 붙여넣기 |
| 선택 후 `"ay` / `"ap` | a 레지스터에 복사 / 붙여넣기 |
| 선택 후 `"+y` / `"+p` | 시스템 클립보드에 복사 / 붙여넣기 |
| `"_dd` | 레지스터에 저장하지 않고 현재 줄 삭제 |

번호 레지스터 1~9는 Neovim 기본 삭제·변경 이력으로 유지하고, Yanky 이력은 별도 목록에서 관리합니다.
