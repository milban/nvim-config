# 버퍼와 점프

Neovim에서 파일, 버퍼, 창은 서로 다른 개념이다.

```text
디스크의 파일 -> 메모리의 버퍼 -> 화면의 창
```

- **파일(file)**: 디스크에 저장된 데이터
- **버퍼(buffer)**: Neovim이 메모리에 읽어 들인 편집 대상
- **창(window)**: 버퍼를 화면에 보여주는 영역
- **탭 페이지(tab page)**: 하나 이상의 창을 배치한 화면

하나의 버퍼를 여러 창에서 볼 수 있고, 하나의 창에 서로 다른 버퍼를 번갈아 표시할 수도 있다.

## 상단 파일 탭 사용하기

`bufferline.nvim`으로 열린 버퍼를 상단에 탭처럼 표시한다. 이 목록은 Neovim 탭 페이지와 다르며, 여러 탭 페이지에서 공유한다.

`Space e`로 Neo-tree를 열고 파일에서 `Enter`를 누르면 현재 편집 창에 파일을 열고 상단 목록에 표시한다. 이전 파일도 버퍼로 남는다. Neo-tree의 `t`는 별도의 탭 페이지를 만들 때 사용한다.

| 키 | 동작 |
|---|---|
| `Shift-h` (`H`) | 상단 목록의 이전 버퍼로 이동 |
| `Shift-l` (`L`) | 상단 목록의 다음 버퍼로 이동 |
| `Space bd` | 창 배치를 유지하며 현재 버퍼 닫기 |
| 상단 파일 이름 클릭 | 해당 버퍼로 이동 |
| 상단 버퍼의 닫기 버튼 또는 우클릭 | 창 배치를 유지하며 해당 버퍼 닫기 |

단축키는 Normal 모드에서 사용한다. `H`와 `L`은 기본 화면 위·아래 이동 대신 버퍼 이동으로 사용한다.
버퍼 닫기는 `mini.bufremove`로 처리하며, 저장하지 않은 변경이 있으면 폐기 여부를 확인한다. 기본 선택은 취소(`No`)이며, 변경을 유지하려면 `:w`로 저장한 뒤 닫는다.
탭 페이지 이동은 기존처럼 `gt` / `gT`, 같은 탭의 분할 창 이동은 `Ctrl-w` 다음 `w`를 사용한다.

## 버퍼 확인과 이동

| 명령 | 의미 |
|---|---|
| `:buffers` 또는 `:ls` | 버퍼 목록 표시 |
| `:buffer {번호}` 또는 `:b {번호}` | 번호에 해당하는 버퍼 표시 |
| `:bnext` 또는 `:bn` | 다음 버퍼 표시 |
| `:bprevious` 또는 `:bp` | 이전 버퍼 표시 |
| `<C-^>` | 현재 버퍼와 직전에 사용한 버퍼 사이를 전환 |
| `:bdelete` 또는 `:bd` | 현재 버퍼를 버퍼 목록에서 제거 |

`:ls` 결과에서 버퍼 번호를 확인한 뒤 다음과 같이 이동할 수 있다.

```vim
:ls
:b 3
```

수정한 내용을 저장하지 않은 버퍼는 일반적인 `:bd`로 닫히지 않는다. 먼저 `:write`로 저장하거나, 변경을 버려도 되는 경우에만 `:bd!`를 사용한다.

## 버퍼와 창 닫기의 차이

| 명령 | 의미 |
|---|---|
| `:quit` 또는 `:q` | 현재 창 닫기 |
| `<C-w>q` | 현재 창 닫기 |
| `:bdelete` 또는 `:bd` | 현재 버퍼를 목록에서 제거 |

문서 창에서 `<C-w>q`를 실행하면 문서를 보여주던 창만 닫힌다. 버퍼 자체는 버퍼 목록에 남아 있을 수 있다.

## 점프 목록

점프 목록은 파일 안팎에서 크게 이동한 커서 위치를 기록한다. LSP로 정의나 구현을 찾아간 뒤 원래 코드로 돌아올 때 사용한다.

| 명령 | 의미 |
|---|---|
| `:jumps` | 현재 창의 점프 목록 표시 |
| `<C-o>` | 점프 목록에서 이전 위치로 이동 |
| `<C-i>` | 점프 목록에서 다음 위치로 이동 |

예시:

```text
gri       구현으로 이동
<C-o>     원래 호출 위치로 복귀
<C-i>     구현 위치로 다시 이동
```

점프 목록은 **창마다 따로 존재**한다. 다른 창으로 이동하면 그 창에는 별도의 점프 기록이 있다.

## 직전 버퍼와 직전 위치

두 명령은 비슷해 보이지만 목적이 다르다.

| 명령 | 기준 |
|---|---|
| `<C-^>` | 직전에 사용한 버퍼로 전환 |
| `<C-o>` | 점프 목록에 기록된 직전 위치로 이동 |

LSP 이동에서 정확한 이전 커서 위치로 돌아가려면 `<C-o>`를 사용한다. 두 파일을 번갈아 편집하려면 `<C-^>`가 편리하다.

## 연습

1. `:edit /tmp/buffer-one.txt`로 첫 번째 버퍼를 연다.
2. `:edit /tmp/buffer-two.txt`로 두 번째 버퍼를 연다.
3. `:ls`로 두 버퍼의 번호를 확인한다.
4. `:b {번호}`로 원하는 버퍼를 표시한다.
5. `<C-^>`를 반복해 두 버퍼 사이를 오간다.
6. Lua 코드에서 `gri`로 이동한 뒤 `<C-o>`와 `<C-i>`를 연습한다.
7. `:jumps`로 기록된 위치를 확인한다.

연습용 버퍼를 저장하지 않고 제거해도 된다면 `:bd!`를 사용한다. 현재 문서 창만 닫으려면 `<C-w>q`를 사용한다.
