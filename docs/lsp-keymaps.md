# LSP 단축키

LSP(Language Server Protocol)는 코드의 정의, 구현, 참조와 진단 정보를 Neovim에 제공한다. 아래 기본 단축키는 LSP가 현재 버퍼에 연결된 경우 사용할 수 있다.

## 코드 정보와 이동

| 명령 | 의미 |
|---|---|
| `K` | 커서 아래 기호의 설명 표시 |
| `<C-]>` | 정의로 이동 |
| `gri` | 구현 목록으로 이동 |
| `grr` | 참조 목록 표시 |
| `grt` | 타입 정의로 이동 |
| `gO` | 문서 기호 목록 표시 |
| `<C-o>` | 이동하기 전 위치로 돌아가기 |
| `<C-i>` | 돌아오기 전 위치로 다시 이동 |

`gri`, `<C-]>` 등으로 다른 파일이나 위치로 이동했다면 `<C-o>`로 돌아온다. `<C-i>`를 누르면 점프 목록에서 다시 앞으로 이동한다.

## 코드 변경

| 명령 | 의미 |
|---|---|
| `grn` | 커서 아래 기호의 이름 변경 |
| `gra` | 사용할 수 있는 코드 액션 표시 |

이름 변경과 코드 액션은 여러 파일을 수정할 수 있으므로 실행 후 변경 내용을 확인한다.

## 진단

| 명령 | 의미 |
|---|---|
| `]d` | 다음 진단으로 이동 |
| `[d` | 이전 진단으로 이동 |
| `]D` | 현재 버퍼의 마지막 진단으로 이동 |
| `[D` | 현재 버퍼의 첫 번째 진단으로 이동 |
| `<C-w>d` | 커서 위치의 진단 메시지를 팝업으로 표시 |

## Insert mode에서 사용하기

| 명령 | 의미 |
|---|---|
| `<C-x><C-o>` | LSP 완성 목록을 수동으로 표시 |
| `<C-s>` | 함수 매개변수 정보 표시 |

`<C-x><C-o>`는 Ctrl을 누른 채 `x`를 입력한 다음, 다시 Ctrl을 누른 채 `o`를 입력한다.

## 상태와 도움말 확인

```vim
:LspInfo
:checkhealth vim.lsp
:nmap gr
:help lsp-defaults
```

| 명령 | 의미 |
|---|---|
| `:LspInfo` | 현재 버퍼에 연결된 LSP 클라이언트 확인 |
| `:checkhealth vim.lsp` | LSP 설정 상태 점검 |
| `:nmap gr` | `gr`로 시작하는 Normal mode 매핑 확인 |
| `:help lsp-defaults` | Neovim의 기본 LSP 단축키 도움말 |

## 연습

1. Lua 파일에서 Neovim API 이름 위에 커서를 두고 `K`를 누른다.
2. 함수 호출 위치에서 `gri` 또는 `<C-]>`로 구현이나 정의로 이동한다.
3. `<C-o>`로 원래 위치에 돌아온다.
4. `<C-i>`로 이동한 위치에 다시 간다.
5. 오류가 있는 코드에서 `]d`와 `[d`로 이동하고 `<C-w>d`로 내용을 읽는다.

현재 창을 닫고 코드 창으로 돌아가려면 `<C-w>q`를 사용한다.
